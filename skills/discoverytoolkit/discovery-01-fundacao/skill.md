# discovery-01-fundacao — Roteador de Skills

Este grupo reúne as skills fundamentais do discovery:

- discovery-01-fundacao-planejar.md
- discovery-02-fundacao-indice.md
- discovery-03-fundacao-bootstrap-templates.md

## Execução automática em sequência

Quando o usuário pedir para **executar a fundação** ou **executar o discovery fundação**, execute as skills nesta ordem, uma após a outra, sem pular etapas:

### Passo 1 — Planejar
Leia e execute integralmente as instruções de `discovery-01-fundacao-planejar.md`.
Aguarde a conclusão e a geração do arquivo `PLANO-DISCOVERY-YYYY-MM-DD.md` antes de prosseguir.

### Passo 2 — Índice
Leia e execute integralmente as instruções de `discovery-02-fundacao-indice.md`.
Aguarde a geração/atualização dos arquivos `arquivos-workspace.txt` e `arquivos-legado.txt` antes de prosseguir.

### Passo 3 — Bootstrap de Templates
Leia e execute integralmente as instruções de `discovery-03-fundacao-bootstrap-templates.md`.
Confirme ao usuário a conclusão de cada etapa.

## Como usar manualmente

1. Leia o arquivo da skill desejada para instruções detalhadas.
2. Siga a ordem sugerida: planejar → índice → templates.
3. Consulte este roteador para referência rápida.
