# Skill: discovery-80-consolidacao

Consolida e cruza informações de fluxos, telas, endpoints e tabelas do Discovery Toolkit.

## Objetivo
- Gerar matriz de dependências entre fluxos, telas, endpoints e tabelas.
- Exportar em JSON e Markdown para uso humano e automação.
- Facilitar navegação, análise de impacto e documentação viva.

## Saídas
- `consolidacao.json`: estrutura cruzada para automação.
- `consolidacao.md`: tabela navegável para consulta rápida.

## Exemplo de uso
- Geração de hyperlinks automáticos entre artefatos.
- Apoio à skill de documentação HTML.
- Base para análise de impacto de mudanças.

## Como funciona
1. Varre arquivos de fluxo (CF-XXX), tela (TELA-XXX), endpoints e tabelas.
2. Monta matriz cruzada (fluxo-tela-endpoint-tabela).
3. Exporta resultados em JSON e Markdown.
