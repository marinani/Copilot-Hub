## I. Escola de Arquitetura da Informação (01-04)

> Filosofia: «Dados não são decoração, são material de construção»

### 01. Pentagram — Estilo Michael Bierut

**Filosofia**: Tipografia é linguagem, grid é pensamento
**Características principais**:

- Cores extremamente contidas (preto/branco + 1 cor de marca)
- Interpretação moderna do sistema suíço de grid
- Tipografia como linguagem visual principal
- Uso estratégico de espaço negativo (60%+ de espaço em branco)

**DNA de Prompt**:

```
Estilo Pentagram/Michael Bierut:
- Hierarquia tipográfica extrema, família Helvetica/Univers
- Grid suíço com espaçamento matemático preciso
- Preto/branco + uma cor de destaque (#HEX)
- Arquitetura da informação como estrutura visual
- 60%+ de proporção de espaço em branco
- Visualização de dados como decoração principal
```

**Obra representativa**: Identidade da campanha de Hillary Clinton 2016
**Palavras-chave de busca**: pentagram hillary logo system

---

### 02. Stamen Design — Poesia dos Dados

**Filosofia**: Tornar os dados uma paisagem tangível
**Características principais**:

- Pensamento cartográfico aplicado ao design de informação
- Formas orgânicas geradas por algoritmo
- Paleta de cores quentes para visualização de dados (ocre, verde sálvia, azul escuro)
- Sistema de camadas interativas

**DNA de Prompt**:

```
Estética Stamen Design:
- Abordagem cartográfica para visualização de dados
- Padrões orgânicos gerados por algoritmo
- Paleta quente (terracota, verde sálvia, azuis profundos)
- Informação em camadas como mapas topográficos
- Sensação artesanal apesar da precisão digital
- Sombras suaves e profundidade
```

**Obra representativa**: Mapa de surto da COVID-19
**Palavras-chave de busca**: stamen covid map visualization

---

### 03. Information Architects — Princípio do Conteúdo Primeiro

**Filosofia**: Design não é decoração, é a arquitetura do conteúdo
**Características principais**:

- Clareza extrema na hierarquia de conteúdo
- Uso apenas de fontes do sistema (otimizado para leitura)
- Manutenção da tradição de hyperlinks azuis
- Performance é estética

**DNA de Prompt**:

```
Filosofia Information Architects:
- Hierarquia de conteúdo primeiro, zero elementos decorativos
- Apenas fontes do sistema (SF Pro/Roboto/Inter)
- Hyperlinks azuis clássicos (#0000EE)
- Comprimento de linha otimizado para leitura (66 caracteres)
- Divulgação progressiva de profundidade
- Design com muito texto e carregamento rápido
```

**Obra representativa**: App iA Writer
**Palavras-chave de busca**: information architects ia writer

---

### 04. Fathom Information Design — Narrativa Científica

**Filosofia**: Cada pixel deve carregar informação
**Características principais**:

- Rigor de periódico científico + elegância do design
- Visualização precisa de dados quantitativos
- Tons profissionais e sóbrios (cinza, azul marinho)
- Design de notas e sistema de referências

**DNA de Prompt**:

```
Estilo Fathom Information Design:
- Estética de periódico científico encontra design moderno
- Visualização precisa de dados (gráficos, linhas do tempo, dispersão)
- Esquema neutro (cinzas, azul marinho, uma cor de destaque)
- Design de notas de rodapé/citações integrado ao layout
- Sem serifa limpo (GT America/Graphik)
```

**Palavras-chave de busca**: fathom information design gates foundation

## Instruções de Uso dos Prompts

**Fórmula de combinação**: `[DNA do prompt de estilo] + [Template de cenário (veja scene-templates.md)] + [Conteúdo específico]`

### Princípio Central: Descreva o Humor, Não o Layout (Mood, Not Layout)

O segredo da geração de imagens por IA: prompts curtos > prompts longos. Descrever 3 frases de humor e conteúdo funciona melhor que 30 linhas de detalhes de layout.

| Escrita que mata a diversidade                                         | Escrita que estimula a criatividade                          |
| ---------------------------------------------------------------------- | ------------------------------------------------------------ |
| Especificar proporção de cores (60%/25%/15%)                           | Descrever o humor ("warm like Sunday morning")               |
| Determinar posição do layout ("título centralizado, imagem à direita") | Referenciar estética específica ("Pentagram editorial feel") |
| Limitar pose e expressão do personagem                                 | Deixar a IA interpretar o estilo naturalmente                |
| Listar todos os elementos visuais a incluir                            | Descrever o que o público deve sentir                        |

### Exemplos Bom / Ruim

**Ruim — Restrição excessiva (IA gera vazio e plano):**

```
Professional presentation slide. Dark background, light text.
Title centered at top. Two columns below. Left column: bullet points.
Right column: bar chart. Colors: navy 60%, white 30%, gold 10%.
Font size: title 36pt, body 18pt. Margins: 40px all sides.
```

**Bom — Orientado por humor (geração diversa e com qualidade):**

```
A data visualization that feels like a Bloomberg Businessweek
editorial spread. The key number "28.5%" should dominate the
composition like a headline. Warm cream tones with sharp black
typography. The data tells a story of dramatic channel shift.
```

### Seleção do Caminho de Execução

Escolha de acordo com a coluna "Melhor Caminho" da tabela rápida:

- **IA Generativa**: Estilos com elementos visuais definidos (06/07/12/13/14/15/16/20), use Gemini/Midjourney para saída direta
- **Renderização HTML**: Estilos que dependem de tipografia precisa (01/03/04/10/11/17/18), código controla dados e layout
- **Híbrido**: HTML para estrutura/esqueleto + IA para imagens/fundo (02/05/08/09/19)

### Controle de Qualidade

1. ❌ Não escreva diretamente "in the style of Pentagram" → ✅ Use descrições de características de design específicas
2. Texto em geração por IA frequentemente erra → Substitua o texto após a geração
3. Proporções facilmente distorcidas → Especifique claramente a proporção de aspecto
4. Gere primeiro 3-5 variações, selecione a melhor e refine

**Zona de exclusão estética padrão** (o usuário pode sobrescrever conforme sua marca):

- ❌ Neon cyberpunk/fundo azul escuro (#0D1117)
- ❌ Imagem de capa com crédito pessoal/marca d'água
