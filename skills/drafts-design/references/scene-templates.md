## 1. Capa de Artigo WeChat / Imagem de Destaque

**Especificações**:

- Imagem de capa: 2.35:1 (900×383px ou 1200×510px)
- Ilustração do corpo do texto: 16:9 (1200×675px) ou 4:3 (1200×900px)

**Elementos-chave de Design**:

- Prioridade de impacto visual (o usuário passa rapidamente pelo feed)
- Pouco ou nenhum texto (o título do artigo será sobreposto)
- Saturação de cor moderada (ambiente de leitura do WeChat é claro)
- Evitar detalhes excessivos (a miniatura deve ser reconhecível)

**Estilos Recomendados**: 01 Pentagram / 11 Build / 12 Sagmeister / 18 Kenya Hara / 07 Field.io

**Template de Prompt de Cena**:

```
[Inserir DNA do Estilo aqui]
- Article cover image for WeChat subscription
- Landscape format, 2.35:1 aspect ratio
- Bold visual impact, minimal or no text
- Moderate color saturation for white reading environment
- Must remain recognizable as thumbnail
- Clean composition with clear focal point
```

## 2. Ilustração de Corpo de Texto / Ilustração Conceitual

**Especificações**:

- 16:9 (1200×675px) mais versátil

- 4:3 (1200×900px) adequado para conteúdo denso

- Serve ao argumento do artigo, não é decoração
- Cria ritmo visual com o contexto

## 4. Apresentação PPT / Keynote

**Especificações**:

- Padrão: 16:9 (1920×1080px)
- Widescreen: 16:10 (1920×1200px)

**Elementos-chave de Design**:

- Uma mensagem central por slide (sem acumular)
- Hierarquia de tamanho de fonte clara (título 40pt+ / corpo 24pt+ / notas 16pt+)
- Bastante espaço em branco, mais nítido na projeção
- Proporção imagem-texto de pelo menos 60:40
- Sistema visual consistente (cores, fontes, espaçamento)

**Estilos Recomendados**: 01 Pentagram / 10 Müller-Brockmann / 11 Build / 18 Kenya Hara / 04 Fathom

**Template de Prompt de Cena**:

```
[Inserir DNA do Estilo aqui]
- Presentation slide design, 16:9
- One core message per slide
- Clear type hierarchy (title 40pt+, body 24pt+)
- Generous whitespace for projection clarity
- Consistent visual system throughout
- [Light/Dark] theme
```
